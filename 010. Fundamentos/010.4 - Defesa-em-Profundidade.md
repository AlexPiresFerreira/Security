# 🛡️ Defesa em Profundidade

> Estratégia de segurança com múltiplas camadas de proteção.
> Ver também: [[CIA-Triad]] | [[IAAA]] | [[Risco-e-Vulnerabilidades]] | [[012.1 - CIS-Controls]]

---

## 📌 Conceito

**Defesa em Profundidade** usa **múltiplas camadas** de controles.
Se uma camada falhar, as outras continuam protegendo.

> 🏰 **Analogia:** Castelo medieval
> `Fosso → Muralha Externa → Portão → Muralha Interna → Torre`

---

## 🏰 As 7 Camadas de Defesa
```

┌─────────────────────────────────────┐ │ 1. Políticas e Awareness │ ├─────────────────────────────────────┤ │ 2. Segurança Física │ ├─────────────────────────────────────┤ │ 3. Perímetro de Rede │ ├─────────────────────────────────────┤ │ 4. Rede Interna │ ├─────────────────────────────────────┤ │ 5. Host / Endpoint │ ├─────────────────────────────────────┤ │ 6. Aplicação │ ├─────────────────────────────────────┤ │ 7. Dados │ └─────────────────────────────────────┘

```

## 1️⃣ Políticas, Procedimentos e Awareness

> Primeira linha de defesa — **pessoas e processos**

### Políticas Essenciais
- Política de Senhas (mínimo 12 chars, MFA obrigatório)
- Política de Uso Aceitável (AUP)
- Política de Classificação de Dados
- Política de Acesso Remoto
- Política de BYOD

### Security Awareness
- Treinamento de onboarding
- Treinamento anual obrigatório
- Simulações de phishing
- Campanhas de conscientização

### Procedimentos Operacionais
- Incident Response Plan → [[Incident-Response]]
- Disaster Recovery Plan (DRP)
- Business Continuity Plan (BCP)
- Change Management

---

## 2️⃣ Segurança Física

> Proteção de instalações e equipamentos

| Controle | Exemplos |
|----------|---------|
| Controle de Acesso | Catracas, RFID, biometria |
| Vigilância | CCTV 24/7, alarmes |
| Proteção de Equipamentos | Salas trancadas, racks, cable locks |
| Infraestrutura | UPS, geradores, ar condicionado redundante |

---

## 3️⃣ Perímetro de Rede

> Proteção na borda da rede (internet ↔ rede interna)

### Firewall de Perímetro
- Stateful Firewall
- NGFW (Next-Generation Firewall)
- WAF (Web Application Firewall) → [[Hardening]]
```

# Regra básica — Default Deny

deny all allow tcp any -> 80,443 # web allow tcp any -> 25 # smtp allow udp any -> 53 # dns

```
### IDS/IPS
- **IDS:** Detecta e **alerta**
- **IPS:** Detecta e **bloqueia**
- Ferramentas: Suricata, Snort, Zeek

### DMZ (Demilitarized Zone)
```

Internet ↓ [Firewall Externo] ↓ [ DMZ ] ← Web, Email, DNS públicos ↓ [Firewall Interno] ↓ [Rede Interna]

```
### VPN
- Site-to-Site: conecta redes
- Remote Access: conecta usuários
- Protocolos: IPSec → [[IPSec]] | OpenVPN | WireGuard

### Proteção DDoS
- Rate limiting
- CDN (Cloudflare, Akamai)
- Scrubbing centers

---

## 4️⃣ Rede Interna

> Proteção dentro da rede corporativa

### Segmentação por VLANs
```

VLAN 10: Servidores (192.168.10.0/24) VLAN 20: Workstations (192.168.20.0/24) VLAN 30: Convidados (192.168.30.0/24) VLAN 40: IoT (192.168.40.0/24) VLAN 50: Gerência (192.168.50.0/24)

```
> 💡 Regra: Convidados e IoT **nunca** acessam rede interna!

### NAC (Network Access Control)
Verifica antes de liberar acesso:
- Dispositivo gerenciado?
- Antivírus atualizado?
- SO atualizado?
- Certificado válido?

### 802.1X
> Ver detalhes → [[802.1x]]
```

Dispositivo → Switch → RADIUS Server (EAP) (valida credenciais)

```
### Network Monitoring
- SIEM → [[Analise-de-Logs]]
- NetFlow/sFlow
- Detecção de anomalias

## 5️⃣ Host / Endpoint

> Proteção de dispositivos individuais

| Controle | Ferramentas |
|----------|------------|
| Antivírus | Windows Defender, Kaspersky, Bitdefender |
| EDR/XDR | CrowdStrike, SentinelOne, MS Defender |
| Host Firewall | Windows Firewall, iptables, pf |
| Disk Encryption | BitLocker, FileVault, LUKS |
| Patch Management | WSUS, SCCM, Ansible |
| App Whitelisting | AppLocker, SELinux |
| Hardening | CIS Benchmarks, STIG → [[Hardening]] |

---

## 6️⃣ Aplicação

> Proteção de aplicações e código

### Secure Coding
- Input validation
- Output encoding
- Prepared statements (anti-SQLi)
- Least privilege
- Error handling seguro
- → Ver [[OWASP-Top-10]]

### Security Testing

| Tipo | Sigla | Ferramenta |
|------|-------|-----------|
| Análise de código | SAST | SonarQube, Checkmarx |
| Análise em execução | DAST | Burp Suite, OWASP ZAP |
| Pentest manual | PT | Metasploit |

### WAF
Protege contra: SQLi, XSS, CSRF, File inclusion, DDoS L7
Soluções: ModSecurity, Cloudflare WAF, AWS WAF

### Autenticação Forte
- MFA → [[IAAA]]
- OAuth 2.0 / OpenID Connect
- Session management seguro

## 7️⃣ Dados

> Último nível — protege o dado em si

### Criptografia por Estado

| Estado | Solução |
|--------|---------|
| Em repouso (at rest) | BitLocker, LUKS, TDE |
| Em trânsito (in transit) | TLS/HTTPS, VPN, SSH |
| Em uso (in use) | Secure enclaves (Intel SGX) |

> Ver detalhes → [[Fundamentos-Cripto]]

### Classificação de Dados

| Nível | Controles |
|-------|----------|
| 🟢 Público | Sem restrições |
| 🟡 Interno | Criptografia em trânsito |
| 🟠 Confidencial | MFA + criptografia + auditoria |
| 🔴 Secreto | Aprovação + criptografia forte + DLP |

### DLP (Data Loss Prevention)
- Bloqueia envio de dados sensíveis por email
- Bloqueia upload para cloud não autorizada
- Bloqueia cópia para USB

### Backup — Estratégia 3-2-1
```

3 cópias dos dados 2 tipos de mídia diferentes 1 cópia offsite

```

## 🎯 Princípios Complementares

| Princípio | Descrição |
|-----------|----------|
| Least Privilege | Acesso mínimo necessário |
| Separation of Duties | Ninguém controla tudo sozinho |
| Fail Secure | Em falha → negar acesso |
| Defense by Obscurity | NÃO é defesa real, só adiciona fricção |

---

## 📊 Exemplo Prático — Defesa Contra Ransomware

| Camada | Controle Aplicado | Resultado |
|--------|------------------|-----------|
| 1. Políticas | Treinamento anti-phishing | Usuário não clica |
| 2. Física | Backup offsite em cofre | Dado preservado |
| 3. Perímetro | IPS bloqueia tráfego C2 | Ataque interrompido |
| 4. Rede | Segmentação impede lateral movement | Dano contido |
| 5. Host | EDR detecta comportamento | Executável bloqueado |
| 6. Aplicação | App whitelisting | Ransomware não executa |
| 7. Dados | Backup permite restauração | Recuperação completa |

> ✅ Mesmo se **1 camada falhar**, as outras protegem!
